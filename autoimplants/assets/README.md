# Landing anatomy asset

`human_femur_hero.stl` is a web-optimized derivative of **Human femur.stl** by Eric Bauer and the donor-based undergraduate human anatomy lab at Elon University.

- Source: https://commons.wikimedia.org/wiki/File:Human_femur.stl
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/
- Changes: Decimated from 173,578 to 10,000 triangular faces for real-time browser rendering. No anatomical features were intentionally altered.
- Optimized asset SHA-256: `a4bd5fc78eed691c007022054b0d2c102233839faebb3c3ae52c167dce90bc88`

This model is used only as the landing-page presentation object. Uploaded case anatomy and validation continue to use the case-specific femur mesh.
